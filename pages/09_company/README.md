# 店舗概要ページ（デザイン案）

- `index.html` … ブラウザで開ける確認用ページ（PC／スマホ自動切り替え・noindex）
- `company_wp-block.html` … WordPressの固定ページ「店舗概要」にカスタムHTMLブロックで丸ごと貼る本体

## 構成（matsumoto-benriya.com/company/ を参考）
1. ページ見出し（ロゴ・COMPANY・店舗概要）
2. 目次
3. STORE：店舗情報（屋号・代表者・所在地・作業拠点・設立・電話・FAX・メール・対応地域・主な業務・お支払い・許可・インボイス番号・取引銀行・所属・主な取引実績）
4. GREETING：代表のご挨拶（とは／大切にしていること3つ）
5. PROFILE：代表プロフィール（氏名・出身・生年月日・経歴・資格・趣味）
6. ACCESS：所在地・対応エリア・Googleマップ
7. CONTACT：電話・メール・LINE
8. 画面下の固定バー

情報はヒアリングシート（Googleドキュメント）から入れています。
