# パートナー募集ページ（デザイン案）

- `index.html` … ブラウザで開ける確認用ページ（PC／スマホ自動切り替え・noindex）
- `partner_wp-block.html` … WordPressの固定ページ「パートナー募集」にカスタムHTMLブロックで丸ごと貼る本体

## 構成（matsumoto-benriya.com/partner/ を参考）
1. ページ見出し（ロゴ・PARTNER・パートナー募集中）と中央のお問い合わせボタン
2. 目次
3. ABOUT 地域で協力できる事業者の皆さまへ
4. FIELD 協力をご相談したい分野（6つ・引越し含む）
5. CONDITION 募集の内容（分野・対象地域＝入間市を中心に半径12km以内）
6. FLOW お問い合わせから協力までの流れ（3ステップ）
7. CONTACT 送ってほしい内容・メールフォームを開くボタン（中央）
8. 画面下の固定バー
