## 2. トレジャーキングの強み（競合が持っていないもの）

1. **ミツモアで評価5.0・口コミ49件・実績52件** — 入間市の便利屋で最強クラス。サイトに必ず転載（掲載許可・スクショ）
2. **産業廃棄物収集運搬許可を埼玉県・東京都の両方で保有** — 便利屋でここまで持っている業者は少ない
3. **古物商許可＋鑑定・査定歴13年以上＋趣味が古美術品鑑定** — 「片付け費用を買取で相殺」「骨董・美術品の目利きがいる遺品整理」は他社にない武器
4. **都県境をまたいで動ける**（入間＋青梅・瑞穂・羽村・福生）。埼玉側の業者は東京側を、東京側の業者は埼玉側を取りこぼしている
5. **法人取引実績（管理会社・法律事務所・物流会社など）** — 法人・空き家・原状回復ニーズの信頼材料
6. **大型免許・二種免許・ゴンドラ特別教育・解体／建築経験** — 「大きいもの・高いところ・重いもの」に強い
7. **2013年創業・13年の地元営業**

## 3. 盛り込んでほしいこと（ヒアリングシートの不足分）

### A. 必ず埋めてほしい項目

| 項目 | 理由・お願い |
|---|---|
| **加入保険**（賠償責任保険の会社名・補償額） | 空欄です。お助けマスター等のFCは保険を前面に出しています。未加入なら加入を推奨 |
| **集客を強化したいジャンルを3つに** | 現在「不用品・庭仕事・解体・害虫駆除」の4つ残っています。おすすめは **①蜂の巣駆除 ②不用品回収・買取（遺品整理含む） ③草刈り・伐採**。解体は②③の関連サービスとして掲載 |
| **ジャンル別の固定料金表** | 時間単価だけでは比較で負けます。下記4項目を出してください<br>・蜂の巣：アシナガ／スズメ／ミツバチ別、高所・屋根裏の加算<br>・不用品：軽トラ積み放題／2t積み放題／単品（冷蔵庫・洗濯機・ベッド等）<br>・草刈り：1㎡あたり（手刈り／機械刈り）、刈草処分費<br>・伐採：高さ別1本あたり |
| **施工事例の写真**（作業前・作業後） | 1ジャンル5件以上、合計15件以上。「場所（入間市◯◯）・作業時間・料金」をセットで |
| **お客様の声** | ミツモアの口コミ49件の転載OK確認、Googleの口コミ、手書きアンケートがあれば写真 |
| **代表の顔写真・作業中の写真・車両写真** | 「どんな人が来るか」が一番の不安材料。笑顔の写真1枚と、作業服姿・トラックの写真 |
| **入間市との関わり** | 出身は山梨県とのこと。入間市に住んで何年か、なぜ入間に来たか、地元で好きな場所（例：彩の森入間公園、狭山茶、入間基地の航空祭 など）、地域活動 |
| **LINE公式アカウント** | 「写真を送るだけで概算見積」は今や必須。未開設ならこちらで用意します |
| **当日・緊急対応の可否** | 蜂は「今日来てほしい」が大半。「最短◯分で駆けつけ」「当日対応OK」の目安 |
| **見積・キャンセルの規定** | 「見積後キャンセル無料」「見積額から追加請求なし」を明記できるか |

### B. 確認させてほしい点

- **メールアドレス欄にフォームのURLが混ざっています**（formzu）。既存の問い合わせフォームでしょうか？
- **電話番号**：HPには050のコールトラッカー番号を載せ、FAX（04-）は法人・高齢者向けに併記する形でよいか
- **既存サイト treasure-king.net** の扱い（新サイトに統合するか、残すか）。ドメインの評価を引き継げる可能性があります
- **「エナジック株式会社 代理店」は便利屋サイトには載せない**ことを推奨します（便利屋の信頼材料にならず、かえって不安を与える可能性があるため）
- **家庭の不用品回収の許可の書き方**：家庭から出るごみは「一般廃棄物」で、産業廃棄物の許可では回収できません。サイト上は「買取（古物商）」「市の許可業者と連携して適正処理」など、**実態に合った表現**に整える必要があります。現在どのように処分しているか教えてください
- **遺品整理士**の資格取得のご予定（遺品整理で検索上位を狙う場合に強い材料になります）
- **スタッフ人数・車両の台数と種類**（軽トラ／2t など）
- **定休日**（年中無休か）、土日祝・早朝・夜間の割増の有無

### C. 対応エリアの具体化
半径12kmを、ページに載せる市町名で確定させてください。

- 埼玉県：**入間市**（豊岡・東金子・金子・宮寺・藤沢・西武の各地区）、狭山市、所沢市、飯能市、日高市
- 東京都：青梅市、瑞穂町、羽村市、福生市（あきる野市・武蔵村山市を入れるかもご判断ください）
- 最寄り駅：入間市駅・仏子駅・元加治駅・武蔵藤沢駅・金子駅

### 型と比べてトレジャーキング側で足りない材料
- 参考サイトの代表あいさつは「出身地・生年・趣味」＋3段ストーリー。田口さんは生年・出身地・趣味は記入済み。**入間に来た経緯**だけ不足
- 参考サイトの店舗概要には「加入保険」が入っています → **加入保険の記入が必須**
- 参考サイトは電話番号が「050（計測用）＋折り返し080」の2段構え → ヒアリングシートの番号でそのまま対応可能
