# 街の便利屋さんトレジャーキング 新サイト制作

埼玉県入間市の便利屋「街の便利屋さんトレジャーキング」（代表 田口純一）の新しいホームページを制作するためのリポジトリです。

- 目的：「入間市 便利屋」「入間市 スズメバチ駆除」「入間市 不用品回収」で地域1位を取り、電話とLINEの問い合わせを増やす
- 参考にする型：https://matsumoto-benriya.com/
- 既存サイト：https://www.treasure-king.net/（ドメインはそのまま引き継ぐ予定）
- 本番の構築：WordPress（VK／Lightning）

---

## 制作の方針（必ず守る）

- **特定の口コミサイト名（ミツモアなど）やそのリンクはサイトに出さない。** お客様がそちらに流れてしまうため。口コミは「口コミサイトの評価」のように抽象的に書く
- **代表の顔写真はこれから撮影する。** それまではデザインに顔写真を入れない
- **トレジャーキングは便利屋。** ハチ駆除の専門店ではないので、ハチの巣駆除はサービスの1つとして、不用品回収・買取、遺品整理、草刈りなどと同じ重さで扱う

---

## フォルダの構成

```
README.md                  ← このファイル（全体の案内・ページの進み具合）
docs/                      ← 調査・指示書・プロンプト
  01_競合調査と追記事項.md
  02_デザイン指示書_ClaudeDesign.md
  03_ClaudeDesign用プロンプト.md
  04_トップページ_改善点.md
  05_口コミ調査.md
  06_トップページ修正依頼プロンプト.md
pages/                     ← Claude Design で作ったページのデザイン案（1ページ1フォルダ）
  01_top/                  ← トップページ
    index.html             ← ブラウザで開くとそのまま見られる
    assets/img/            ← そのページで使っている画像
    README.md
assets/                    ← 写真の原本
  from-old-site/           ← 既存サイトから取得した画像（元のファイル名のまま）
  for-design/              ← Claude Design に渡す用に名前を付け直した実写写真
  treasureking_design_assets.zip  ← for-design をまとめたもの
```

## 新しいページを追加するとき

1. Claude Design で作ったページを zip で書き出す
2. `pages/` の下に、上の表の番号とフォルダ名で展開する（例：`pages/02_hachi/index.html`）
3. 上の表の「状態」を「デザイン案あり」に書き換える
4. コミットして GitHub に保存する

## 確認待ちの項目（田口さんへ）

- 加入保険（会社名・補償額）
- 料金の統一：既存サイトの「出張費3,000円＋作業費3,000円/時間」か、ヒアリングシートの「出張費2,200円（初回無料）＋作業費3,300円/時間」か
- 営業時間：既存サイトの 10:00〜18:00 か、ヒアリングシートの 7:00〜23:00 か
- 見積後のキャンセル無料にできるか
- 入間市に来た経緯・地元とのつながり（代表あいさつ用）
- 営業時間が口コミサイトの掲載（6:00〜0:00）・既存サイト（10:00〜18:00）・新サイト（7:00〜23:00）で違う
- 施工事例の「場所・作業時間・人数・料金」
