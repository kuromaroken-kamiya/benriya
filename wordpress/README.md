# WordPress 固定ページ 実装手順

テーマ：Lightning（VK）を想定。どのページも「カスタムHTML」ブロック1つに貼るだけで表示できるようにしてあります。CSSは各ページの外側に効かないようにしてあるので、テーマの見た目は崩れません。

## 1. このフォルダの中身

```
wordpress/
├── README.md                    ← この手順書
├── 固定ページ/                  ← 各固定ページに貼るファイル（中身を丸ごとコピー）
│   ├── 01_トップページ.html
│   ├── 02_店舗概要.html
│   ├── 03_対応エリア.html
│   ├── 04_よくある質問.html
│   ├── 05_お問い合わせ.html
│   └── 06_パートナー募集.html
├── アップロードする画像/
│   └── treasureking/            ← トップページの画像14点（フォルダごとアップロード）
└── tools/                       ← デザイン案を差し替えたときに作り直す道具
```

## 2. 作る固定ページ

| No. | タイトル | スラッグ（URL） | 貼るファイル |
|---|---|---|---|
| 01 | トップページ | （ホームページに設定） | `01_トップページ.html` |
| 02 | 店舗概要 | `company` | `02_店舗概要.html` |
| 03 | 対応エリア | `area` | `03_対応エリア.html` |
| 04 | よくある質問 | `faq` | `04_よくある質問.html` |
| 05 | お問い合わせ | `contact` | `05_お問い合わせ.html` |
| 06 | パートナー募集 | `partner` | `06_パートナー募集.html` |

**スラッグは上のとおりにしてください。** トップページのボタンやメニューがこのURLにつながっています。

## 3. 手順

### ① 画像をアップロード（トップページ用・最初に1回）
`アップロードする画像/treasureking/` フォルダを、サーバーの `wp-content/uploads/` の中にフォルダごとアップロードします（サーバーのファイルマネージャーかFTPで）。
アップロード後、`https://（ドメイン）/wp-content/uploads/treasureking/logo.png` をブラウザで開いてロゴが出ればOKです。
※メディアライブラリからアップロードすると保存先が `uploads/年/月/` になり、パスが合わなくなります。その場合はトップページのファイル内の `/wp-content/uploads/treasureking/` を一括で置き換えてください。

### ② 固定ページを作る（6ページ分くり返す）
1. 固定ページ → 新規追加
2. タイトルとスラッグ（右側の「URL」）を上の表のとおりに入れる
3. 「＋」→「カスタムHTML」ブロックを追加
4. `固定ページ/` の該当ファイルをテキストエディタで開き、**全部コピーして**ブロックに貼る（先頭の `<!-- wp:html -->` ごと貼ってOK）
5. ページ編集画面の「Lightning デザイン設定」で
   - レイアウト：**1カラム（サイドバーなし）**
   - **ページヘッダー（タイトル）とパンくずを非表示**（各ページのデザインに見出しとパンくずが入っているため。出したままだと見出しが二重になります）
6. 公開

### ③ トップページの設定
設定 → 表示設定 →「ホームページの表示」を「固定ページ」にして、ホームページに「トップページ」を選ぶ。

### ④ フォントとテーマ側の設定
- 文字は「Noto Sans JP」を前提にしています。外観 → カスタマイズ（Lightning のフォント設定）で Noto Sans JP を選んでください。選べない場合も代わりのゴシック体で表示されるので崩れはしません
- 各ページの**画面下に電話・メール・LINEの固定バーが入っています**。VK All in One Expansion Unit の「モバイル固定ナビ」などテーマ側の固定ボタンを使っている場合は、二重になるのでテーマ側をオフにしてください
- ヘッダーとフッターはテーマのものを使います（トップページのデザイン案にあったヘッダー・フッターは外してあります）

### ⑤ メニュー（外観 → メニュー）
トップページ／店舗概要／対応エリア／よくある質問／お問い合わせ／パートナー募集
（「サービス内容」は、サービスのページができてから追加します）

## 5. 公開前チェック

- [ ] 6ページすべてスマホとPCで表示を確認（横にはみ出さないか）
- [ ] トップページの画像が全部出ているか
- [ ] 電話ボタン（050-1882-0301）、メールフォーム、LINEが開くか
- [ ] トップページのボタン・メニューから各ページに移動できるか
- [ ] 見出しが二重になっていないか（テーマのページタイトルを非表示にしたか）
- [ ] 画面下の固定バーが二重になっていないか
- [ ] 設定 → 表示設定の「検索エンジンでの表示」で、**検索エンジンにインデックスさせない** のチェックが外れているか（公開時）
- [ ] 【要確認】の赤いラベルが残っていないか（トップページの料金「既存サイトとの料金の統一」など）

## 6. まだリンク先がないもの

トップページの次のボタンは、ページができる予定のURLにつないであります。ページを作るまではリンク切れになります。

| ボタン | つないであるURL | ページ |
|---|---|---|
| ハチの巣駆除のページへ | `/hachi/` | 未作成 |
| 不用品回収・買取のページへ | `/fuyouhin-kaitori/` | 未作成 |
| 草刈り・伐採のページへ | `/kusakari-bassai/` | 未作成 |
| 法人のお客様へ | `/houjin/` | 未作成 |
| ブログ一覧を見る | `/blog/` | 投稿一覧ページ（設定 → 表示設定の「投稿ページ」で `blog` を指定） |

トップページの「新着情報・ブログ」の記事3件は見本です。ブログ記事を表示するには、この部分をテーマの「最近の投稿」ブロックに置き換えます。

## 7. デザイン案を差し替えたとき

`pages/` のデザイン案を新しくしたら、リポジトリの一番上で次を実行すると、このフォルダの中身が作り直されます。

```bash
wordpress/tools/collect.sh
```

トップページのリンク先を変えたいときは `tools/build_top_block.py` の `LINKS` を書き換えてから実行します。
