# 街の便利屋さんトレジャーキング 新サイト トップページ（デザイン案）

Claude Designで作ったトップページのデザイン案を、そのまま開ける静的HTMLにしたものです。

- `index.html` … 1ファイルでPC版とスマホ版を表示（画面幅1000px以上でPC版、未満でスマホ版）
- `assets/img/` … 使用している写真（WebP／PNG）

## 確認方法
- ローカル：`index.html` をブラウザで開く
- GitHub Pages：Settings → Pages で `main` ブランチのルートを公開すると、URLで共有できます

## 注意
- デザイン確認用の見本です（検索エンジンに載らないよう `noindex` を入れています）
- 「要確認」の赤いラベルは、確認待ちの仮文言です
- WordPress（VK／Lightning）で組むときの見本として使います
